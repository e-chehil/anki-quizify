# Quizify Card Markdown v1

Quizify Card Markdown 是 Quizify Markdown 加载项的一次性批量导入格式。它面向
Typora 等普通 Markdown 编辑器，不负责源文件与 Anki 笔记之间的同步，也不写入
稳定 ID。

## 文件与版本

- 文件使用 UTF-8；允许 UTF-8 BOM，换行会规范化为 LF。
- YAML front matter 可选，且只能出现在文件开头。
- `quizify.format` 是本格式的版本号。省略时等同于 `1`；v1 解析器拒绝其他值。
- YAML 只读取顶层 `quizify` 映射，其他顶层配置留给 Typora 或其他工具。
- 为避免执行任意 YAML 构造，v1 只支持缩进映射、块列表、行内列表和简单标量。

```yaml
---
title: 其他工具可以读取
quizify:
  format: 1
  deck: 学习::网络
  tags: [网络, 每日]
  media:
    local: copy
    remote: keep
    roots:
      - ./assets
---
```

## 卡片边界

结构标记必须不缩进、独占一行；行尾空格或制表符会被忽略。

| 标记 | 含义 |
| --- | --- |
| `+++` | 结束上一张卡片并开始下一张卡片的 `Front` |
| `***` | 结束当前 `Front` 并开始 `Back` |
| 文件末尾 | 结束最后一张卡片 |
| `---` | 普通 Markdown 分隔线；仅文件首行可开始 YAML |

第一段非空正文必须是 `+++`。每张卡片必须有非空 `Front` 和恰好一个 `***`；
空 `Back` 允许，但会产生警告。紧邻结构标记的字段首尾空行会裁掉，字段内部内容
原样保留。

围栏代码块和 `$$ ... $$` 公式块中的标记不是结构标记。普通正文若需要一个字面量
标记行，写成 `\+++` 或 `\***`；导入字段时会去掉开头的反斜杠。

## 文档配置

| 键 | 类型 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `format` | 整数 | `1` | 格式版本 |
| `deck` | 非空字符串 | 无 | 未单独指定牌组的卡片目标 |
| `tags` | 字符串列表 | `[]` | 添加到文档内所有卡片；标签不能含空白 |
| `media.local` | `copy` / `keep` / `error` | `copy` | 本地媒体处理方式 |
| `media.remote` | `keep` / `error` | `keep` | 远程媒体处理方式 |
| `media.roots` | 相对路径列表 | `[]` | 显式声明媒体子目录；仍不得离开 Markdown 所在目录 |

未知的 Quizify 配置会产生警告并忽略，以便发现拼写错误。绝对媒体根目录、任何
通过 `..` 或符号链接越过 Markdown 所在目录的路径、缺失文件都会在写入 Anki 前
诊断。源文档不能自行授权读取其他本地目录。

## 卡片配置

可选的卡片配置必须是 `Front` 的第一个非空块：

```markdown
+++
<!-- quizify-card
deck: 学习::网络::TCP
tags: [TCP, 重点]
draft: false
-->
Front 正文
***
Back 正文
```

| 键 | 类型 | 默认值 | 合并规则 |
| --- | --- | --- | --- |
| `deck` | 非空字符串 | 文档牌组 | 卡片值覆盖文档值 |
| `tags` | 字符串列表 | `[]` | 文档标签在前，去重合并 |
| `draft` | 布尔值 | `false` | `true` 时预览但不导入 |

没有牌组的卡片使用导入窗口中的默认牌组。卡片配置注释会从 `Front` 中移除；其他
HTML 注释仍是普通字段内容。

## 媒体

v1 识别行内 Markdown 图片 `![说明](相对路径)`、尖括号目标
`![说明](<含空格的相对路径>)` 和 Quizify 音频 `!audio[标题](相对路径)`。
围栏/缩进/行内代码、HTML 注释和公式块中的相似文本不作为媒体引用。

`copy` 模式通过 Anki 媒体管理器复制文件，再用 Anki 返回的最终文件名改写字段。
可见 Markdown 路径会进行 URL 编码；字段末尾还会生成不可见的 HTML 媒体清单，
使 Anki 的“检查媒体”和 `.apkg` 导出能找到这些原本只存在于 Markdown 中的引用。
该清单不写回源文件，`quizify-media` 注释名属于加载项保留区域。

远程 URL 在 `keep` 模式下保持原样并产生离线警告，不会由加载项下载。本地
`keep` 也不复制文件，因此通常不适用于同步或 `.apkg` 导出。

## 预览、去重与提交

- 文件选择器支持一次多选，不递归扫描目录。
- 任一读取、解析或媒体预检错误都会阻止整批提交；警告不会阻止。
- 默认去重方式是在当前 Quizify 笔记类型内比较规范化后的完整 `Front + Back`，
  两者都相同才跳过。用户可以改为全部创建。
- `draft: true` 的卡片不参与提交。
- 牌组创建与笔记批量写入合并成一个 Anki 撤销项。
- Anki 的媒体文件不属于资料库撤销事务；撤销导入不会删除已复制媒体，以免影响
  其他笔记。可稍后使用 Anki 的“检查媒体”清理未使用文件。

## v1 非目标

- 不生成 QuizifyID，不更新或删除已有笔记，不监视源文件。
- 不递归导入目录，不下载远程媒体。
- 不解释 YAML anchor、alias、tag、block scalar 或 flow mapping。
- 不承诺识别 reference-style 图片、Obsidian embed 或任意 HTML 媒体标签。
