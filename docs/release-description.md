# Quizify（开务）：Anki Markdown 交互式题型插件

> 「开务」取意于“开物成务”：理解事物之理，并使学习真正落实为可用之功。

Quizify（开务）是对早期模板 **Quizify（格致）** 的延续和重构。旧版“格致”主要是一个可导入的 Anki 卡片模板；新版“开务”则升级为 Anki 插件：它会自动创建并维护 `Quizify Markdown` 笔记类型，让你直接在 `Front` / `Back` 字段中书写 Markdown，并渲染为填空、选择、折叠、标签页、批注、揭示、随机遮罩背诵、音频播放器、代码高亮、数学公式等交互式学习内容。插件现在同时提供现代「开务」与复古「格致」两套可选外观，二者共用同一套功能和数据结构。

## 核心特点

- **Markdown 优先**：在 Anki 字段中直接写 Markdown，减少富文本编辑带来的格式污染。
- **交互式题型**：支持填空题、单选题、多选题、点击揭示、批注弹窗、折叠块、标签页、音频控件和随机遮罩背诵。
- **Quizify Workbench**：统一设计配置面板与 Anki 编辑工具栏，提供高频格式与题型的一键按钮、快捷键、语法诊断、结构预览和窄窗口适配。
- **Knowledge Canvas 视觉系统**：统一模板骨架、Markdown 排版和全部题型状态，兼顾浅色、深色、桌面与移动端展示。
- **代码与公式**：支持 `marked` Markdown 渲染、`highlight.js` 代码高亮与行号、KaTeX 数学公式。
- **Markdown 扩展**：支持 `==高亮==`、`^上标^`、`~下标~` 和 GitHub
  风格 Note/Tip/Important/Warning/Caution 提示框。
- **完整离线运行**：内置 Markdown、代码高亮、公式、净化器与字体，并在同步前验证 SHA-256 清单。
- **正式客户端适配**：支持 Anki Desktop 25.09+ 的加载项消息桥和 AnkiDroid 2.24+ 的正式 JavaScript API。
- **悬浮复习控制**：点击依次显示填空、选择、揭示、批注和折叠内容；
  正面完成后自动翻面，背面支持四向拖拽评分。
- **嵌套内容定位**：揭示前自动激活标签页、展开祖先折叠块并滚动到目标。
- **位置持久化**：长按悬浮按钮后可拖动位置，设置保存在当前设备。

## 与 Quizify（格致）的关系

- 旧版“格致”是手动导入模板；新版“开务”会自动创建/刷新笔记类型和模板。
- 旧版语法与新版语法并非完全一致。新版更接近 Markdown 扩展语法，便于复杂内容嵌套和长期维护。
- 建议新笔记使用新版 `Quizify Markdown` 笔记类型；旧卡片如需迁移，请先复制少量内容测试语法差异。

## 安装方法

### 从本地安装包安装

1. 在 Anki 桌面端进入 `工具` -> `插件`，选择“从文件安装”。
2. 打开发布包 `quizify_markdown.ankiaddon`，然后重启 Anki。
3. 进入需要使用 Quizify 的用户资料（profile），打开 `工具` -> `Quizify Markdown` -> `设置…`。
4. 执行“校验并重新同步媒体”；多个 profile 需要分别执行。
5. 完成一次包含媒体的 Anki 同步。移动端同步完成后，请强制关闭并重新打开客户端。

AnkiDroid 和 AnkiMobile 不能直接安装桌面加载项；它们通过 Anki 同步接收笔记类型模板和 Quizify 媒体。正式 AnkiWeb 插件代码尚未发布，不应使用占位代码安装。

## 初次使用

安装并重启后，新建笔记时选择 `Quizify Markdown` 笔记类型。

该笔记类型包含两个纯文本字段：

- `Front`：卡片正面内容。
- `Back`：卡片背面内容。

你可以在任一字段中书写 Markdown 和 Quizify 扩展语法。复习时，插件会自动将内容渲染为交互式卡片。

## Quizify 语法速览

### 填空题

```
HTTP 默认端口是 {{80}}。
```

复习时会显示输入框，并根据答案给出反馈。

### 单选题

```
;;;
A. TCP
B. UDP
C. HTTP
;;;C
```

答案行只有一个字母时，渲染为单选题。

### 多选题

```
;;;
A. GET
B. POST
C. BANANA
D. PUT
;;;ABD
```

答案行包含多个字母时，渲染为多选题。

### 点击揭示

```
[[三次握手发生在哪一层？||传输层]]
```

点击后显示隐藏答案。

### 批注弹窗

```
TCP 是一种[面向连接]^(发送数据前需要先建立连接)^的协议。
```

点击正文中的术语后显示批注。

### 折叠块

```
::: 查看解析
这里可以写 Markdown 内容。
:::
```

适合放置解析、补充说明、例题步骤等内容。

### 标签页

```
=== 概念
TCP 提供可靠传输。

=== 对比
UDP 更轻量，但不保证可靠传输。
===
```

适合在同一张卡片中组织多个并列视角。

### 音频播放器

```
!audio[听力片段](example.mp3)
```

请先把音频文件加入 Anki 当前资料的媒体库，并在语法中填写媒体文件名。播放器支持播放/暂停、重播、A/B 片段循环和倍速；不需要额外网络托管。

### 随机遮罩背诵

```markdown
:::: recite mask=40 mode=mixed
TCP 是一种 %%面向连接%%、可靠的传输层协议。
::::
```

背诵块会按比例随机遮挡候选词语。点击可切换遮罩，长按可临时偷看；鼠标或触控笔按住滑动时会连续揭示经过的遮罩。手机端需先稳定长按约 380ms，看到“滑动揭示”提示后继续拖动；普通滑动仍用于页面滚动，单纯长按仍是临时偷看。底部可以调整比例或重新洗牌。`mode=auto` 使用自动分词，`mode=manual` 只使用 `%%...%%` 分组，`mode=mixed` 同时启用两者。

### 代码块与公式

````
```javascript
console.log("Quizify");
```

行内公式：$E = mc^2$

块级公式：
$$
\int_0^1 x^2 dx = \frac{1}{3}
$$
````

也支持 `\(...\)` 行内公式和 `\[...\]` 块级公式。四种定界符内的
内容会作为完整 TeX 交给 KaTeX，不再触发 Markdown、上下标、填空、揭示等
扩展；反引号代码、代码围栏和原始 HTML 代码元素中的公式写法保持为代码。
行内定界符需在同一行闭合；跨行显示公式的起止定界符应独立成行；普通美元
符号请写成 `\$`。公式渲染还限制数量、源码长度和展开次数，并拒绝 `\def`、
`\gdef`、`\newcommand` 等可变宏定义，避免短公式放大为过量页面节点。

## 编辑器工具栏

当你编辑 `Quizify Markdown` 笔记时，插件会在 Anki 原生工具栏下方显示 Quizify 工具栏。

工具栏提供：

- Markdown 格式与 Quizify 题型全部使用一键直达按钮。
- `Ctrl+Alt+1` 到 `Ctrl+Alt+8` 快捷插入。
- Markdown 格式按钮，以及 `Ctrl+B`、`Ctrl+I`、`Ctrl+K`、
  `Ctrl+Shift+H` 等选区包裹快捷键。
- 当前字段语法诊断与结构预览。
- 独立的当前字段真实渲染预览，不写入答题进度，也不会触发翻面或评分。
- 工具栏去除品牌栏和分组面板，全部入口按编辑区实际宽度自然换行；预览位于按钮流末尾，与其他入口同尺寸并以强调色区分，极窄窗口也无需横向滚动。

快捷键对应关系：

| 快捷键 | 插入内容 |
| --- | --- |
| `Ctrl+Alt+1` | 填空 |
| `Ctrl+Alt+2` | 选择题 |
| `Ctrl+Alt+3` | 点击揭示 |
| `Ctrl+Alt+4` | 批注 |
| `Ctrl+Alt+5` | 折叠块 |
| `Ctrl+Alt+6` | 标签页 |
| `Ctrl+Alt+7` | 音频 |
| `Ctrl+Alt+8` | 随机遮罩背诵 |

## 内置资源与离线使用

Quizify（开务）内置以下前端库：

- `marked`
- `highlight.js`
- `KaTeX`

代码行号由 Quizify 自带的 review 模块生成，不依赖额外的 line-numbers 插件。

模板只引用随插件发布的本地资源。插件启动时验证文件大小与 SHA-256，只把新增或变化的文件写入当前资料的媒体库。设置窗口中的“校验并重新同步媒体”可用于修复损坏的媒体副本。

## 设置项

在 Anki 中进入 `工具` -> `Quizify Markdown` -> `设置…` 可以打开设置窗口。

当前主要选项：

- **无卡片背景**：移除复习卡片背景和阴影，让内容更贴近 Anki 原生显示。
- **悬浮复习控制**：启用逐项揭示、自动翻面和拖拽评分。
- **AnkiDroid API**：优先通过正式 0.0.3 合约执行显示答案和评分；关闭后仍可使用仅限 Android 的客户端兼容入口。
- **校验并重新同步媒体**：检查内置资源并修复当前资料的媒体副本。

悬浮复习控制在桌面端通过加载项消息桥、在 AnkiDroid 上通过正式 API 或 Android 限定兼容入口执行自动翻面和评分。AnkiMobile 与 AnkiWeb 提供基础渲染和本地逐项揭示，但不会模拟客户端私有点击来翻面或评分。

## 兼容性说明

- 主要支持 Anki Desktop 25.09+ 与 AnkiDroid 2.24+；较早 AnkiDroid 通过仍存在的 reviewer globals 尽力兼容。
- AnkiMobile 与 AnkiWeb 支持基础内容渲染和本地逐项揭示，不支持自动翻面或评分。
- 安装或升级插件前，建议先备份 Anki 资料库。

## 常见问题

### 安装后没有看到 `Quizify Markdown` 笔记类型

请重启 Anki，并确认插件已启用。插件会在资料库打开时自动创建或刷新笔记类型。

### Markdown 没有渲染

打开 `工具` -> `Quizify Markdown` -> `设置…`，执行“校验并重新同步媒体”，然后重新同步资料并重启客户端。

### 升级后移动端仍在使用旧悬浮球

先在桌面端安装新版插件并执行“校验并重新同步媒体”，完成一次完整同步；随后让移动端完成媒体同步，并强制关闭后重新打开客户端。Quizify 的复习脚本使用固定媒体文件名，已经打开的 WebView 可能暂时保留旧资源。

### 公式没有渲染

打开 `工具` -> `Quizify Markdown` -> `设置…`，执行“校验并重新同步媒体”，确认 KaTeX 字体和运行时完整，再重启 Anki。

### 旧版“格致”语法能否直接使用

不保证完全兼容。新版“开务”采用新的 Markdown 扩展语法，建议按本文档中的语法创建新卡片；旧内容迁移前请先备份并小范围测试。
